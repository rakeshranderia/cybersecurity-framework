# NIST Cybersecurity Framework

## Overview

The NIST Cybersecurity Framework (CSF) provides a flexible approach for managing cybersecurity risk.

The framework can be used by organisations of different sizes and sectors to understand cybersecurity risk, establish priorities and communicate security outcomes.

---

## Core Functions

The framework is organised around five core functions:

| Function | Objective |
|---|---|
| **Identify** | Understand assets, risks, dependencies and business context |
| **Protect** | Implement safeguards to reduce cybersecurity risk |
| **Detect** | Identify cybersecurity events and potential incidents |
| **Respond** | Take action when cybersecurity incidents occur |
| **Recover** | Restore capabilities and improve resilience |

---

## Executive Application

The NIST CSF is particularly useful as a communication framework because it connects technical security activities with organisational risk.

A CIO or CISO can use the framework to:

- Establish a common cybersecurity language
- Assess current capability
- Identify gaps
- Prioritise investment
- Track improvements
- Communicate risk to executives and the Board

---

## Practical Assessment

A practical assessment should consider:

- Critical business services
- Information assets
- Technology dependencies
- Existing security controls
- Third-party dependencies
- Threat exposure
- Incident response capability
- Recovery capability

---

## Executive Perspective

The value of NIST CSF is not simply in implementing individual controls.

Its greatest value is providing a common structure for answering:

**What do we have? → What could happen? → How are we protected? → How would we know? → How would we respond? → How would we recover?**

---

## Relationship to Other Frameworks

NIST CSF can complement:

- ISO/IEC 27001
- Essential Eight
- SOC 2
- APRA CPS 234
- Internal security policies and controls

The framework should be used as a risk management and communication tool rather than treated as a compliance checklist.
