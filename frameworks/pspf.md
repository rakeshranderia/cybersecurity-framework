# Protective Security Policy Framework

## Overview

The Australian Government Protective Security Policy Framework (PSPF) provides policy requirements for protecting government people, information and assets.

The framework provides a useful reference point for organisations operating in environments where information protection, security governance and assurance are critical.

---

## Core Security Areas

The PSPF covers areas including:

- Governance
- Information security
- Personnel security
- Physical security
- Security governance and assurance
- Security risk management

---

## Executive Application

From a technology leadership perspective, the PSPF reinforces the importance of treating security as an organisational responsibility.

Technology leaders should consider:

- Information classification
- Access management
- Personnel security
- Physical security
- Security governance
- Security risk
- Third-party access
- Assurance activities

---

## Information Security

Information should be protected according to its sensitivity, value and potential impact if compromised.

This requires consideration of:

- Classification
- Access controls
- Handling requirements
- Storage
- Transmission
- Disposal
- Monitoring
- Incident management

---

## Executive Perspective

The PSPF demonstrates the importance of taking a holistic approach to security.

Effective security requires alignment between:

**People + Process + Technology + Physical Security + Governance**

Technology controls alone cannot provide complete organisational protection.
