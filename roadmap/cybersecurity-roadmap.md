# Cybersecurity Roadmap

## Overview

A cybersecurity roadmap provides a structured approach for improving security capability over time.

The roadmap should be risk-driven and aligned to business priorities rather than implemented purely as a checklist of technical controls.

---

## Phase 1 — Establish

**Objective:** Understand the current security environment and establish foundational governance.

Key activities:

- Identify critical systems and information
- Establish security governance
- Define security roles and responsibilities
- Develop baseline security policies
- Establish risk assessment methodology
- Review identity and access controls
- Assess current Essential Eight maturity
- Identify major security gaps

**Outcome:**

A clear understanding of the organisation's current security posture, risks and priorities.

---

## Phase 2 — Strengthen

**Objective:** Address the highest-priority security risks and improve foundational controls.

Key activities:

- Strengthen identity and access management
- Implement or improve MFA
- Improve vulnerability and patch management
- Strengthen endpoint protection
- Improve backup and recovery capability
- Implement security monitoring
- Improve security awareness
- Establish third-party security assessments
- Formalise incident response

**Outcome:**

Improved protection against common threats and reduced exposure to material security risks.

---

## Phase 3 — Mature

**Objective:** Establish measurable and sustainable security capabilities.

Key activities:

- Implement security metrics and reporting
- Mature security operations and monitoring
- Improve threat detection and response
- Conduct regular security testing
- Integrate security into project delivery
- Mature supplier risk management
- Conduct regular disaster recovery exercises
- Improve security architecture
- Establish formal control assurance

**Outcome:**

A measurable and repeatable cybersecurity operating model.

---

## Phase 4 — Optimise

**Objective:** Continuously improve security capability based on risk, threat intelligence and business requirements.

Key activities:

- Automate security processes
- Integrate security telemetry
- Apply threat intelligence
- Improve predictive risk analysis
- Regularly review security architecture
- Optimise security investment
- Benchmark against industry practices
- Continuously improve security controls

**Outcome:**

A proactive and continuously improving cybersecurity capability.

---

## Executive Reporting

Cybersecurity roadmaps should provide executives and Boards with clear visibility of:

- Current security posture
- Material cybersecurity risks
- Security maturity
- Key remediation initiatives
- Investment requirements
- Emerging threats
- Regulatory obligations
- Control effectiveness
- Residual risk

Technical metrics should be translated into **business risk and business impact** wherever possible.

---

## Guiding Principle

> **Cybersecurity maturity is a journey, not a destination.**

The appropriate level of security investment should be determined by organisational risk, regulatory obligations, business criticality and the potential impact of security incidents.
